# AI PicChanger+SEO

Мультиплатформенная браузерно-серверная платформа с мультиагентным ИИ-оркестром для автоматизированного создания продающих карточек товаров, редактируемой инфографики, рич-контента и комплексной SEO-оптимизации каталогов e-commerce.

## Ключевые возможности
- **Цикл «Пилот ➔ Утверждение дизайна ➔ Серия»**: генерация эталонной карточки, доработка векторных слоев поверх растрового фона и пакетное масштабирование на тысячи SKU.
- **Неблокирующая фоновая очередь**: асинхронная обработка каталогов с сохранением чекпоинтов в БД, поллингом статуса и прогресс-баром в реальном времени.
- **Мультиформатный графический конвейер**: экспорт в WebP, прогрессивный JPEG, AVIF и PNG с настройкой качества и контролем контрастности WCAG 2.1.
- **Безопасная интеграция с CMS**: изолированный адаптер WooCommerce + плагин-мост `ai-catalog-bridge.php` (v1.1.0), 4 правила защиты существующих шорткодов и видео, генерация SEO товаров и категорий.
- **Гибкие вычислительные контуры (`APP_MODE`)**: `DEV_MOCK` (локальная отладка без расхода токенов), `CLOUD_API` (облачные шлюзы ИИ с шифрованием ключей AES-256 и лимитером бюджета), `GPU_SERVER` (выделенный сервер с watchdog-автостопом).

## Структура проекта
- `frontend/` — клиентское SPA-приложение (React 18 + Vite 6 + TypeScript + Tailwind CSS v4 + react-konva) + Nginx Docker-образ.
- `backend/` — серверное ядро (FastAPI + ИИ-оркестратор + FSM + фоновый воркер + коннекторы CMS) + Docker-образ.
- `wordpress_bridge/` — лёгкий PHP-плагин (`ai-catalog-bridge.php` v1.1.0) для расширения REST API WooCommerce.
- `tests/` — изолированные сквозные и интеграционные автотесты (`pytest`).

## Быстрый старт на локальном ПК (контур `DEV_MOCK`)

### 1. Запуск Backend
```bash
cd backend
py -3.13 -m venv .venv   # или py -3.14 -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
APP_MODE=DEV_MOCK uvicorn main:app --reload --port 8000
```

### 2. Запуск Frontend
```bash
cd frontend
npm install
npm run dev
```
После запуска откройте адрес, который выведет Vite в терминале (обычно `http://localhost:5173`).

### 3. Запуск автотестов
```bash
pytest -v
```

## Production-запуск через Docker Compose
1. Скопируйте `.env.example` в `.env` и укажите `APP_MODE=CLOUD_API`, `MASTER_KEY` и ключи провайдеров.
2. Запустите сборку и контейнеры:
```bash
docker compose up -d --build
```
Веб-интерфейс будет доступен на порту `8080` (`http://localhost:8080`), API — через встроенный прокси `/api/`.
