# AI PicChanger+SEO

Мультиплатформенная браузерно-серверная платформа с мультиагентным ИИ-оркестром для автоматизированного создания продающих карточек товаров, редактируемой инфографики, мини-лендингов, рич-контента и комплексной SEO-оптимизации каталогов e-commerce.

## Ключевые возможности
- **Цикл «Пилот ➔ Утверждение дизайна ➔ Серия»**: генерация эталонной карточки, фиксация фонов и эластичных плашек поверх растра и пакетное масштабирование на тысячи SKU.
- **Автономный режим без подключения к CMS**: ручное добавление локальных фото с описанием с ПК или импорт таблиц Excel/CSV с выгрузкой готового ZIP-архива (`images/<SKU>/slide_*.webp` + `catalog_ready.xlsx` + `catalog_ready.csv`).
- **Студийная графика и лендинги**: локальное удаление фона на CPU (`rembg`), библиотека пользовательских фонов/плашек, форматы холста (`1:1`, `3:4`, `9:16`, `16:9` и ручные `px`), логотип бренда и конструктор мини-лендинга товара с изолированным HTML.
- **Неблокирующая фоновая очередь**: асинхронная обработка каталогов с сохранением чекпоинтов в БД, поллингом статуса и прогресс-баром в реальном времени.
- **Мультиформатный графический конвейер**: экспорт в WebP, прогрессивный JPEG, AVIF и PNG с настройкой качества и контролем контрастности WCAG 2.1.
- **Безопасная интеграция с CMS**: изолированный адаптер WooCommerce + плагин-мост `ai-catalog-bridge.php` (v1.1.0), 4 правила защиты существующих шорткодов и видео, генерация SEO товаров и категорий.
- **SaaS-контур и токен-биллинг**: регистрация/вход (JWT HS256), мультитенантная изоляция данных по пользователю, антиабьюз-защита приветственных токенов (100 токенов на устройство/e-mail) и админ-панель.
- **Гибкие вычислительные контуры (`APP_MODE`)**: `DEV_MOCK` (локальная отладка без расхода токенов), `CLOUD_API` (облачные шлюзы ИИ с шифрованием ключей AES-256 и лимитером бюджета), `GPU_SERVER` (выделенный сервер с watchdog-автостопом).
### Монетизация, контроль резерва API ИИ и встроенный чат поддержки (Релиз v1.2 — Сессия 11)
- [x] **Гибкие пакеты токенов и динамический редактор тарифов:** Стартовые пакеты (`Start` 200 ток. / $10, `Pro` 1000 ток. / $45, `Business` 5000 ток. / $200) в `backend/configs/billing_tariffs.json` с возможностью редактирования цен, объёмов токенов, активности пакетов и себестоимости токена (`cost_per_token_usd`) администратором без перезапуска сервера (`BillingConfigOverride`).
- [x] **Платёжный шлюз по паттерну «Стратегия» и идемпотентный Webhook:** Модели `PaymentOrder`, адаптеры `DevMockPaymentProvider` (для контура `DEV_MOCK`) и `HmacGatewayPaymentProvider` (`HMAC-SHA256`), эндпоинты `POST /api/billing/orders`, `GET /api/billing/orders` и `POST /api/billing/webhook/{provider}` с защитой от повторного начисления при дублировании Webhook.
- [x] **Финансовый контроль резерва API ИИ (`SolvencyGuard`):** Учёт фактического баланса средств на счетах ИИ-провайдеров (`ProviderWallet`, `ProviderLedgerEntry`), автоматическая сверка с обязательствами перед клиентами (`required_reserve_usd = client_tokens * cost_per_token_usd`), расчёт суммы рекомендованного пополнения и статусы здоровья (`HEALTHY` / `WARNING` / `CRITICAL`).
- [x] **Встроенный чат поддержки с бейджем непрочитанных:** Модель `SupportMessage`, плавающий виджет `SupportWidget.tsx` с индикатором непрочитанных ответов (`unread_count`), раздел входящих обращений клиентов в админ-панели (`AdminFinanceAndSupport.tsx`) и опциональная пересылка уведомлений на `ADMIN_EMAIL` (SMTP) и/или в Telegram.


## Структура проекта
- `frontend/` — клиентское SPA-приложение (React 18 + Vite 6 + TypeScript + Tailwind CSS v4 + react-konva) + Nginx Docker-образ.
- `backend/` — серверное ядро (FastAPI + ИИ-оркестратор + FSM + фоновый воркер + коннекторы CMS + токен-биллинг) + Docker-образ.
- `wordpress_bridge/` — лёгкий PHP-плагин (`ai-catalog-bridge.php` v1.1.0) для расширения REST API WooCommerce.
- `tests/` — изолированные сквозные и интеграционные автотесты (`pytest`).

## Быстрый старт на локальном ПК (контур `DEV_MOCK`)

### 1. Запуск Backend
```bash
cd backend
py -3.13 -m venv .venv   # или py -3.14 -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
APP_MODE=DEV_MOCK uvicorn main:app --reload --port 8000
```

### 2. Запуск Frontend
```bash
cd frontend
npm install
npm run dev
```
После запуска откройте адрес, который выведет Vite в терминале (обычно `http://localhost:5173`).

### 3. Запуск автотестов
```bash
pytest -v
```

## Production-запуск через Docker Compose
1. Скопируйте `.env.example` в `.env` и укажите `APP_MODE=CLOUD_API`, `MASTER_KEY`, `ADMIN_EMAIL` и ключи провайдеров.
2. Запустите сборку и контейнеры:
```bash
docker compose up -d --build
```
Веб-интерфейс будет доступен на порту `8080` (`http://localhost:8080`), API — через встроенный прокси `/api/`.
